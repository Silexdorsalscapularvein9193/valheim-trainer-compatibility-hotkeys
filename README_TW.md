## 為什麼需要這個工具

彙整遊戲版本、修改器版本及熱鍵記錄。這是獨立參考資料，不是 FLiNG 官方下載或已驗證的修改器版本。

目前儲存庫包含文件與介面概念設計，沒有經過驗證的可執行版本。相容性記錄和圖片不是執行測試，也不能證明官方身分、支援版本或帳號保護。

## 開始之前

- 準備好 **遊戲建構+訓練師構建**，並確認它屬於目標 Valheim 設定或連線。
- 變更設定之前，記錄目前遊戲/用戶端版本或資料日期。
- 先選擇 **診斷日誌** 的儲存位置，避免覆蓋上一次結果。
- 先用 **訓練器和遊戲版本矩陣** 進行一次短測試，並保留原始存檔、設定或比較記錄。

## 主要功能

### 01 · 訓練器和遊戲版本矩陣

將訓練器版本與偵測到的可執行檔和遊戲版本相符。

### 02 · 選項和熱鍵索引

列出選項組、目前狀態和熱鍵，而不隱藏衝突。

### 03 · 儲存備份提醒

記錄附件和選項失敗，並提供足夠的上下文來重現它們。

## 介面說明

- **01.** 遊戲和訓練器版本相容性矩陣。
- **02.** 具有可執行和特權狀態的進程檢測卡。
- **03.** 按功能分組的選項索引。
- **04.** 帶有衝突警告的熱鍵列表。
- **05.** 測試前診斷日誌和儲存備份提醒。

## 完成第一次使用

1. 開啟 **Valheim 修改器相容性與快捷鍵參考**，確認偵測到的 Valheim 版本或資料來源。
2. 選擇輸入或設定，只調整 **訓練器和遊戲版本矩陣**，先保留與本次測試無關的預設值。
3. 在預覽或狀態面板檢查 **選項和熱鍵索引**，處理版本、篩選或辨識警告。
4. 只執行一次可控制的操作。在修改第二項設定之前，將實際結果與預覽比較。
5. 儲存設定或匯出結果，並保留 **儲存備份提醒** 以便比對或還原。

## 如何理解結果

相容性優先於選項計數。偵測到的建置不符的進程不是成功的附件。啟用一個選項，透過場景變化觀察並記錄結果；該序列將熱鍵衝突、臨時值和不支援的指標分開。

## 適合使用情境

- 比賽訓練器和遊戲版本
- 尋找選項熱鍵
- 診斷過程檢測

## 遊戲更新之後

- [ ] 在進程檢測之前比較遊戲可執行檔和訓練器版本。
- [ ] 在測試熱鍵之前解決權限和可執行檔名稱變更問題。
- [ ] 啟用一個可逆選項並透過場景重新載入來觀察它。
- [ ] 保留舊的診斷日誌並保存備份，直到確認新的配對。

## 問題排查

> **常見問題:** 訓練師找不到Valheim進程.

### 找不到進程

檢查可執行檔案名稱、權限等級以及遊戲是否已達到支援的狀態。

### 熱鍵什麼都不做

解決重複的綁定並確認所選的訓練器版本與遊戲相符。

### 選項在場景之間關閉

閱讀持久性註釋並將其與遊戲重寫的選項分開測試。

## 資料與還原

在測試之前備份儲存並一次啟用一個選項。建置、進程和熱鍵詳細資訊應保留在診斷日誌中，以便乾淨回滾。
