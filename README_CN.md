## 故障排查

> **常见故障:** 训练师找不到Valheim进程.

### 找不到进程

检查可执行文件名称、权限级别以及游戏是否已达到支持的状态。

### 热键什么都不做

解决重复的绑定并确认所选的训练器版本与游戏匹配。

### 选项在场景之间关闭

阅读持久性注释并将其与游戏重写的选项分开测试。

## 数据与恢复

在测试之前备份保存并一次启用一个选项。构建、进程和热键详细信息应保留在诊断日志中，以便干净回滚。
